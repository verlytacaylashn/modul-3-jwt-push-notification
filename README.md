# Modul 3 - JWT dan Push Notification

Project Praktikum Pemrograman Mobile.

## Teknologi
- Backend: Node.js dan Express
- Database: MySQL
- Authentication: JSON Web Token (JWT)
- Mobile: React Native dengan Expo
- API Testing: Postman

## Struktur Project
Struktur backend dan mobile akan ditambahkan sesuai modul praktikum.

## Cara Menjalankan
Petunjuk instalasi dan menjalankan aplikasi akan dilengkapi setelah implementasi selesai.
